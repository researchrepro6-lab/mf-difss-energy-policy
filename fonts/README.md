# Fonts used in the matplotlib figures

Latin Modern Sans 10 (regular, bold, oblique, bold oblique), the OpenType version of the
sans-serif Computer Modern family used by LaTeX. The figures use it for text and the
Computer Modern math fonts bundled with matplotlib (`mathtext.fontset = "cm"`) for symbols,
so that figure text matches the typeset manuscript. The fonts are distributed under the
GUST Font License (`GUST-FONT-LICENSE.TXT`), which permits redistribution.
